Introduction

What is agentburp?

A headless, CLI-first, agent-native HTTP intercepting proxy and bug bounty toolkit designed from the ground up for terminal power-users and LLM security agents.

For two decades, GUI proxies like Burp Suite Professional and OWASP ZAP have defined manual web application penetration testing. However, modern engineering has fundamentally changed: developers ship code non-stop with Cursor, Claude Code, and GitHub Actions, while autonomous security agents require high-speed, programmatic, JSON-driven tooling.

agentburp strips away the heavyweight Java GUI, memory bloat, and manual mouse clicks. It condenses Burp's battle-tested workflow into a single compiled Go binary backed by an embedded SQLite database, strict declarative YAML scope enforcement, and a native Model Context Protocol (MCP) stdio server.

Proxy

Intercepts HTTP/1.1 traffic, validates against strict scope rules, and writes full request/response pairs directly into SQLite.

agentburp proxy start

HTTP History

Query, search, and filter captured transactions by host, HTTP method, status code, or regular expression body matches.

agentburp hist list

Repeater

Replay stored requests with overridden headers, modified auth tokens, and custom bodies without altering original baseline logs.

agentburp repeat <id>

Fuzzer

Fuzz query and body parameters over wordlists or numeric ranges, automatically flagging status and body anomalies.

agentburp fuzz <id>

Diffing

Structurally compare two requests side-by-side: status code variations, response lengths, header differences, and body deltas.

agentburp diff <a> <b>

Heuristic Scanner

Analyzes transactions for high-value bug bounty candidates: IDOR patterns, open redirects, CORS flaws, JWT tokens, and SSRF hints.

agentburp scan <id>

Bug Bounty PoC Reporting

Instantly turn validated vulnerabilities into professional, platform-compliant Markdown writeups ready for HackerOne and Bugcrowd submissions.

agentburp report <id> --format hackerone

MCP Server for AI Agents

Expose the entire proxy, history, repeater, and scanner toolkit to Claude Desktop, Cursor, and autonomous security agents over JSON-RPC stdio.

agentburp mcp-serve --scope scope.yml

Zero Dependencies

Installation

No Git clone, Go toolchain, or npm required. Download the precompiled, standalone binary for your platform using one line.

Option A: Graphical Setup Installer (NSIS — Recommended)

Download the official Windows installer. Sets up user-space installation, configures PATH automatically, and adds Start Menu shortcuts with zero admin privileges required:

Download agentburp-setup.exe

Option B: One-Line Automated PowerShell Install

Runs from any directory (including C:\Windows\System32) without permission issues, installs to %LOCALAPPDATA%\Programs\agentburp, and adds to your user PATH:

irm https://raw.githubusercontent.com/jojin1709/agentburp/main/install.ps1 | iex

Option C: Portable Standalone Executable

Download single binary: agentburp.exe

Download and set execution permissions on Linux AMD64 / ARM64:

curl -sSL -o agentburp https://github.com/jojin1709/agentburp/releases/latest/download/agentburp-linux-amd64 && chmod +x agentburp

For Apple Silicon Macs (M1 / M2 / M3 / M4):

curl -sSL -o agentburp https://github.com/jojin1709/agentburp/releases/latest/download/agentburp-darwin-arm64 && chmod +x agentburp

For Intel-based Mac hardware:

curl -sSL -o agentburp https://github.com/jojin1709/agentburp/releases/latest/download/agentburp-darwin-amd64 && chmod +x agentburp

Compile and install to $GOPATH/bin via Go's official package proxy:

go install github.com/jojin1709/agentburp/cmd/agentburp@latest

Documentation index: pkg.go.dev/github.com/jojin1709/agentburp

Step-by-Step Workflow

Quick Start

From binary download to intercepting, modifying, fuzzing, and producing HackerOne PoC reports in minutes.

01

Download Executable

Grab the binary with PowerShell irm or curl as shown in the Installation section above.

./agentburp --help
02

Configure Target Scope

agentburp enforces a default-deny policy. Download the starter configuration and add your authorized target domain:

# Windows irm https://raw.githubusercontent.com/jojin1709/agentburp/main/examples/scope.yml -OutFile scope.yml # Linux / macOS curl -sSL -o scope.yml https://raw.githubusercontent.com/jojin1709/agentburp/main/examples/scope.yml
03

Start the Proxy Listener

Bind agentburp to your desired local port (defaults to 127.0.0.1:8888):

./agentburp proxy start --addr 127.0.0.1:8888 --scope scope.yml
04

Capture & Search HTTP History

Configure your browser or curl client to route through http://127.0.0.1:8888. Query captured transactions:

./agentburp hist list --host target.com --limit 20 ./agentburp hist show 12
05

Replay with Repeater

Replay stored request #12, overriding headers or request payloads:

./agentburp repeat 12 --set "Authorization: Bearer ATTACKER_TOKEN"
06

Fuzz Parameters for Vulnerabilities

Fuzz an ID parameter over numeric range 1..100. Safe mode requires --confirm:

./agentburp fuzz 12 --param id --range-from 1 --range-to 100 --confirm
07

Run Heuristic Vulnerability Scan

Run heuristic candidate checks on baseline request #12:

./agentburp scan 12
08

Generate Bug Bounty PoC Report

Format confirmed findings into a ready-to-submit HackerOne markdown writeup:

./agentburp report 12 --format hackerone > report.md
Network Interception

Proxy Interceptor

agentburp operates as an HTTP forward proxy. Every request passing through the listener is filtered against the scope guard and recorded to the active workspace's SQLite database.

agentburp proxy start [--addr 127.0.0.1:8888] [--scope scope.yml]

Routing Client Traffic Through agentburp:

# Curl via agentburp curl -x http://127.0.0.1:8888 http://target.com/api/test # Environment Variables export HTTP_PROXY=http://127.0.0.1:8888 export HTTPS_PROXY=http://127.0.0.1:8888
HTTPS Interception Notice
HTTPS traffic is currently handled via a transparent TCP tunnel (pass-through). Full MITM TLS certificate generation and decryption is under active development for v0.2.0.
Persistent Storage

HTTP History Engine

All captured transactions are stored permanently inside ~/.agentburp/history.db. Filter history instantly using structured query flags.

# List entries with filters agentburp hist list --host target.com --method POST --status 200 --limit 50 # Inspect raw request/response headers and body for entry #12 agentburp hist show 12

All history commands stream pure, valid JSON by default, making them instantly pipeable to jq, grep, or LLM agent tool interfaces.

Interactive Replay

Repeater Engine

Replay captured transactions with modified headers, updated tokens, or customized body payloads to test access control and authentication bypasses.

agentburp repeat 12 --set "Authorization: Bearer ATTACKER_TOKEN" --set "X-Forwarded-For: 127.0.0.1" --body '{"role":"admin"}'
Parameter Intruder

Fuzzer & Intruder Engine

Systematically test endpoints against numeric ID ranges or external wordlists. The engine compares every fuzzed response against the baseline and flags anomalies (status mismatches, length deltas, unexpected JSON keys).

# Numeric range IDOR fuzzing agentburp fuzz 12 --param id --range-from 1 --range-to 200 --confirm # Wordlist fuzzing agentburp fuzz 12 --param action --wordlist ./wordlists/actions.txt --anomalies --confirm
Differential Analysis

Differential Analysis Engine

Compare two history entries side-by-side. Crucial for verifying Insecure Direct Object References (IDOR), Broken Object Level Authorization (BOLA), and privilege escalation.

agentburp diff 12 13
Passive & Heuristic

Heuristic Vulnerability Scanner

Runs rule-based heuristic checks over stored transactions to spot high-confidence vulnerability indicators.

agentburp scan 12

Active Scanner Checks:

  • IDOR Candidates: Flags sequential numerical parameters in GET/PUT/DELETE requests.
  • Open Redirect: Scans for redirect parameters (url, redirect, next) paired with 30x responses.
  • CORS Misconfiguration: Checks for Access-Control-Allow-Origin: * on authenticated responses with credentials allowed.
  • JWT Flaws: Inspects Bearer tokens for weak algorithms, missing expiration, or sensitive claims.
  • SSRF Indicators: Flags URL parameters targeting internal IP schemes (127.0.0.1, 169.254.169.254).
PoC Generation

PoC Report Generator

Automate the creation of submission-ready markdown bug reports formatted according to major bug bounty platform standards.

# Generate HackerOne report agentburp report 12 --format hackerone > h1_report.md # Generate Bugcrowd report agentburp report 12 --format bugcrowd > bugcrowd_report.md # Generate Generic Security Advisory Markdown agentburp report 12 --format generic > advisory.md
AI Agent Integration

Model Context Protocol (MCP) Server

agentburp includes a built-in JSON-RPC server operating over standard I/O (stdio), implementing Anthropic's Model Context Protocol. AI assistants can discover endpoints, fuzz parameters, and investigate traffic autonomously.

./agentburp mcp-serve --scope scope.yml

        Security Guarantee
        
Scope Guard & Safety Rails

        

          Security testing requires strict boundaries. agentburp protects testing programs from out-of-scope violations through multiple defense-in-depth safety layers.
        


        

          
          

            
Strict Authorization Requirement

            

              Only test hosts and endpoints you have explicit written permission to assess. agentburp hard-refuses all traffic unless explicitly whitelisted in allow_hosts.
            

          

        


        
    
          
  • Default-Deny Model: Any request to an unlisted host produces an immediate 403 Forbidden block.
    • 
          
  • Deny Always Wins: Entries in deny_hosts override all wildcard allowances (e.g. blacklisting payments.target.com while allowing *.target.com).
    • 
          
  • Safe Mode Guard: When safe_mode: true is active, active intrusive operations (such as fuzzing) fail immediately unless executed with --confirm.
    • 
          
  • Global Token-Bucket Rate Limiter: Enforces strict request throttling across proxy, repeater, and fuzzer calls.
    • 
          
  • Immutable Audit Logging: Active scans and intruder attacks log reasons and payloads to the separate audit_log table in SQLite.
    •

        YAML Specification
        
Configuration Reference (scope.yml)

        

          agentburp uses a lightweight YAML configuration file to enforce boundaries and rate controls.
        


        

          
          workspace: mytarget

allow_hosts:
  - "target.com"
  - "*.target.com"

deny_hosts:
  - "payments.target.com"

rate_limit_per_sec: 10
safe_mode: true

notify:
  webhook_url: ""        # Optional Slack/Discord webhook
  min_confidence: "high"

Real-World Examples

Workflow A: Detecting & Confirming IDOR

        

          # 1. Inspect captured transaction #42
agentburp hist show 42

# 2. Fuzz user ID parameter from 1 to 200
agentburp fuzz 42 --param id --range-from 1 --range-to 200 --confirm

agentburp diff 42 45

agentburp report 45 --format hackerone > idor_writeup.md
        

      


      
      

        Searchable Reference
        
CLI Command Index

        

          Search the entire agentburp CLI syntax. Type to filter instantly:
        


        

          
          
        


        

          
          

            

              agentburp proxy start
              Interceptor
            

            
Starts the forward HTTP intercepting proxy server and records all in-scope traffic into SQLite.

            

              
--addr <host:port>Listen address (default: "127.0.0.1:8888")

              
--scope <file>Path to scope.yml rules (default: "scope.yml")

            

          


          
          

            

              agentburp hist list
              History Query
            

            
Queries and filters captured transactions from the current workspace history database.

            

              
--host <string>Filter by host substring or domain name

              
--method <verb>Filter by HTTP method (GET, POST, PUT, DELETE)

              
--status <code>Filter by exact HTTP status code (200, 302, 403, 500)

              
--body <regex>Search request or response body content via regex

              
--limit <int>Maximum number of results to output (default: 50)

            

          


          
          

            

              agentburp hist show <id>
              Transaction Detail
            

            
Outputs full request and response details, complete headers, duration, and body payload for a transaction ID.

          


          
          

            

              agentburp repeat <id>
              Repeater
            

            
Replays a stored transaction with modified headers or body without mutating the original history entry.

            

              
--set <"Key: Val">Override request header (can be specified multiple times)

              
--body <string>Override request body payload

            

          


          
          

            

              agentburp fuzz <baseline_id>
              Intruder
            

            
Fuzzes a designated query or body parameter against a baseline request, recording anomalies to the audit log.

            

              
--param <name>Parameter name to replace and fuzz (required)

              
--range-from <n>Start integer for numeric sequence

              
--range-to <n>End integer for numeric sequence

              
--wordlist <path>Path to wordlist file

              
--anomaliesOnly print responses that diverge from the baseline (default: true)

              
--confirmExplicit confirmation flag required when safe_mode is enabled

            

          


          
          

            

              agentburp diff <id_a> <id_b>
              Diff
            

            
Compares two stored transactions, calculating status code mismatches, length deltas, and header/body differences.

          


          
          

            

              agentburp scan <entry_id>
              Heuristic Scanner
            

            
Runs automated heuristic vulnerability detection algorithms against a transaction, logging findings to the database.

          


          
          

            

              agentburp report <entry_id>
              Reporting
            

            
Generates a structured bug bounty submission writeup in HackerOne, Bugcrowd, or generic markdown format.

            

              
--format <type>"hackerone", "bugcrowd", or "generic" (default: "generic")

              
--finding-id <n>Specific finding ID to generate report for

            

          


          
          

            

              agentburp workspace use <name>
              Workspace
            

            
Switches the active workspace, isolating captured traffic and findings per target.

          


          
          

            

              agentburp workspace current
              Workspace
            

            
Prints the currently active workspace name.

          


          
          

            

              agentburp mcp-serve
              AI Agent Stdio
            

            
Runs an interactive Model Context Protocol (MCP) server over stdin/stdout for seamless AI agent integration.
