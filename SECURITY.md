---

## Reporting a Vulnerability

As a security-focused project, `agentburp` takes security issues seriously.

If you believe you have discovered a vulnerability in `agentburp` (including scope guard bypasses, local privilege escalations, or unintended traffic leakage):

1. **Do NOT publicly disclose the issue** in open GitHub issues or pull requests.
2. Please reach out to the project author, **[JOJIN JOHN](https://www.linkedin.com/in/jojin-john/)**, or submit a private security report through GitHub Security Advisories at:
   - [Report a Vulnerability](https://github.com/jojin1709/agentburp/security/advisories/new)
3. Include:
   - Type of issue (e.g. scope check bypass, unhandled panic, logic flaw)
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment

You will receive an initial response within 48 hours.

---

## Ethical Use Mandate

`agentburp` is created strictly for authorized bug bounty programs, authorized red team assessments, and ethical web penetration testing. Never use `agentburp` against targets without explicit authorization.
